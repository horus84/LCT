# ProjectTax: Where Constraints Fail

**Phase-Aware Diagnostics and Adaptive Decoding for Tool-Calling Language Models**

This repository contains the codebase to reproduce the experiments measuring "Constraint Tax" and evaluating the "Phase-Aware Constraint Router" (PACR). 

## Structure
- `configs/` - Frozen experimental parameters.
- `scripts/` - Python engine and analysis tools.
- `docs/` - Verified prior work and preregistration.
- `paper/` - LaTeX paper skeleton.
- `data/` and `results/` - Reserved directories for execution outputs.
